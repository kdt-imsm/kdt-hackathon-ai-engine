# 🌱 농촌 일여행 추천 플랫폼 『일멍쉬멍』

> 🏆 **제7회 K-디지털트레이닝(KDT) 해커톤** 고용노동부장관상 우수상 수상작

농가 인구 감소 및 고령화로 농촌 일손 부족 심화되고 있습니다.  
일멍쉬멍은 지역 균형 발전을 위한 디지털 사회서비스, **AI 기반 농촌 일여행 추천 플랫폼**입니다.  

자연어 처리와 벡터 임베딩을 활용하여 농업 일자리와 관광지를 결합한 맞춤형 일여행 일정을 제안합니다.

## 🏛️ 시스템 아키텍처

```
자연어 입력 → OpenAI 임베딩 → PostgreSQL+pgvector → 벡터 유사도 검색 → 농가/관광지 추천 → AI 일정 생성
```

- **자연어 슬롯 추출**: GPT-4o-mini를 통한 자연어 의도 추출
- **OpenAI 임베딩**: text-embedding-3-small로 사용자 선호도 벡터 생성
- **벡터 검색**: 코사인 유사도 검색 구현
- **개인화 추천 엔진**: 사용자 프로필 벡터 기반 추천 시스템
- **규칙 기반 스케줄링**: 전북 지역 특화 규칙과 GPT-4o-mini를 활용한 일정 생성

## 🛠️ 기술 스택

#### 백엔드
- **Python 3.x** - 주 개발 언어
- **FastAPI** - 비동기 웹 프레임워크
- **SQLAlchemy 2.x** - ORM 및 데이터베이스 관리
- **Pydantic** - 데이터 검증 및 직렬화

#### AI 엔진 및 자연어 처리
- **OpenAI API** - GPT-4o-mini (슬롯 추출, 일정 생성)
- **OpenAI Embeddings** - text-embedding-3-small (벡터 임베딩)
- **벡터 검색**: PostgreSQL + pgvector를 통한 의미적 유사도 검색

#### 데이터베이스
- **PostgreSQL** - 관계형 데이터베이스
- **pgvector** - 고차원 벡터 확장 (1536차원 지원)
- **벡터 인덱싱**: 코사인 유사도 고속 검색 (`<->` 연산자)

## 💡 향후 확장 계획

#### 데이터 확장
- **전국 확대**: 전북 이외 지역으로 서비스 확장 (경남, 충남 등 농업 중심 지역)
- **실시간 데이터 연동**: 날씨, 농작물 생육 상태, 농가 가용성 정보 실시간 반영
- **다양한 체험 활동**: 어촌, 산촌 체험, 전통 공예, 농촌 축제 정보 추가

#### 사용자 경험 개선
- **모바일 앱 개발**: 위치 기반 서비스, 오프라인 지도, 실시간 알림 기능
- **소셜 기능**: 여행 후기 공유, 농가 리뷰, 커뮤니티 기능
- **개인화 심화**: 과거 여행 패턴, 계절별 선호도, 동반자 유형별 맞춤 추천

#### AI Agent 시스템 고도화
- **멀티 Agent 오케스트레이션**: 추천 Agent, 스케줄링 Agent, 피드백 Agent 간 협업 시스템
- **농업 일정 최적화**: 농번기/농한기, 작물별 수확 시기, 농가 운영 패턴 종합 고려
- **실시간 피드백 처리**: AI Agent를 통한 즉시 일정 수정 및 재최적화
- **지리적 최적화**: 농촌 지역 교통망, 이동 시간, 접근성 종합 분석
- **개인화 맞춤형**: 사용자 선호도와 과거 피드백 학습 반영
- **농촌 도메인 지식 강화**: 지역별 농업 특성, 계절별 작물 패턴, 기후 데이터 학습
- **하이브리드 AI 모델**: GPT-4o와 농촌 전문 도메인 모델 조합으로 정확도 향상

#### 시스템 성능 향상
- **벡터 검색 최적화**: pgvector 인덱스 튜닝 및 쿼리 성능 개선
- **하이브리드 검색 고도화**: 벡터 유사도와 규칙 기반 필터링의 가중치 최적화
- **캐싱 시스템 도입**: LRU+TTL 캐시를 통한 임베딩 생성 최적화 및 응답 속도 개선
